# Substantial-page MCP delivery receipts

This private adapter binds a licensed MCP evidence projection to the exact released revision, canonical route and deterministic substantial-page package delivered with it. The verifier recomputes the receipt and rejects stale revisions, substituted routes and modified receipt bytes.

The layer is not publicly discoverable. It grants no publication authority, changes no evidence maturity and makes no commercial transaction claim. Calculations remain absent unless a source-bound calculation contract exists; the adapter never fills an empty calculation section with invented numbers.
