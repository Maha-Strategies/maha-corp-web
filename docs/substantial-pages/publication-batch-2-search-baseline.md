## Operator checklist — importing Search Console data

There is **no automated per-page Search Console integration**. The repository has a query-level
import (`POST /api/admin/search-console-import`, the Top queries CSV, market-mapping bearer)
which writes `search_console_query_snapshots` and feeds market mapping. It does **not** capture
per-URL metrics, so the fields below must be collected by hand.

At each window (2026-09-02, 2026-09-09, 2026-09-23):

1. Search Console -> Performance -> Search results. Set the date range to the window.
2. Open the **Pages** tab, filter to the `live` URLs above, and record per URL:
   impressions, clicks, average position.
3. Open the **Queries** tab filtered to each page and record:
   discovered queries, and query breadth (distinct queries returning that page).
4. Run URL Inspection for each URL and record indexed / not indexed, with the reason if not.
5. Re-run the reachability sweep. Any record leaving `awaiting-canonical-release` joins the
   measured cohort from that window onward — note which window it entered, because its
   exposure is shorter than the baseline cohort and the two are not comparable without it.
6. Record results alongside this baseline. Do not overwrite it.

Keep participant, natal, customer, credential and other secret data out of this artifact and its
companions. Impressions, clicks, position, index state and query text are the only fields needed.
